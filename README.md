# マルチお気に入り管理アプリ

複数のWebページをスマホから「お気に入り送信」し、Glideアプリに記録＆整理する仕組みです。

![screenshot](images/how-it-works.jpg)

## 💡 主な特徴

- Safariから「送る」で1タップ登録
- GlideアプリでURL＋画像＋タイトル一覧表示
- EC横断でお気に入り品管理が可能
- iOSショートカット＆Zapier＆Glide構成

## 🧭 使い方ガイド

1. 【必須】以下のショートカットをiPhoneに追加  
   → [iOSショートカットを追加する](https://www.icloud.com/shortcuts/87c6e186a6604ec5bd0dcd455c82c690)

2. Glideアプリを開く（ホーム画面に追加推奨）  
   → [Glideアプリを開く](https://gos-google-sheets-ap-2abv.glide.page)

3. SafariでWebサイト閲覧中に「送信」→「お気に入り送信」を選ぶ  
4. アプリにURL・画像・タイトルが記録されます

## 🛠 使用技術スタック

- iOSショートカット
- Zapier（Webhook + LinkPreview API）
- Glide（Google Sheets連携）
